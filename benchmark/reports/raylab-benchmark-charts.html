RayLab turns idle lab machines into one shared compute pool.

A cross-platform RayLab cluster ran a Monte Carlo option-pricing simulation across Windows and macOS nodes. The same 480 million simulated paths finished more than twice as fast when a second machine joined the job.

What This Demonstrates

  • RayLab can run one Python simulation over a mixed Windows and macOS cluster.
  • The same 480 million paths finished 2.26x faster when RayLab used two nodes instead of one.
  • Monte Carlo is a strong demo workload because every chunk is independent and has tiny result data.
  • The computed option price matched the analytical Black-Scholes price within the measured standard error.
